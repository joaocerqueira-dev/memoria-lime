# Memória e aprendizados · Tema Lime (Irroba) + FigCraft

- `memoria/`: conhecimento do tema Lime (editor, paletas, tipografia, schema, layout), integração com o FigCraft, gerador por script e regras de segurança no painel Irroba. Índice em `MEMORY.md`.
- `conhecimento/`: mapeamento completo do tema Lime (`tema-lime.md`) e das telas de Personalizar Loja (`personalizar-loja.txt`).
- `geradores/figcraft/`: base para gerar mocks no FigCraft via `figcraft-cli run` (`fc.py` constrói os comandos com ids previsíveis; `runcheck.py` executa e confere).

Para reutilizar: copie `memoria/*.md` para `~/.claude/projects/<projeto>/memory/`.
