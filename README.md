# Memória e aprendizados · Tema Lime (Irroba) + FigCraft

- `memoria/`: arquivos de memória do Claude Code (índice em `MEMORY.md`): tema Lime, integração FigCraft, painel Irroba, clientes (Var, Bô, Bell Boots).
- `geradores/`: scripts Python que geram os mocks no FigCraft via `figcraft-cli run` (`fc.py` é a base; `runcheck.py` executa e confere os ids).

Para reutilizar a memória: copie `memoria/*.md` para `~/.claude/projects/<projeto>/memory/`.
Imagens e arquivos `.figcraft` não estão aqui (são pesados).
